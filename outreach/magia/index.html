ANTES DE EMPEZAR

El secreto lo guardas tú.

  1. Piensa un número entero del 0 al 63. No lo escribas ni lo digas.
  2. Mira cada lámina. Si tu número aparece, elige «Sí, está». Si no aparece, elige «No está».
  3. Después de las seis láminas, descubriremos tu número.

¿Te equivocaste? Usa «Volver» para corregir la última respuesta.

EL SECRETO DE LAS LÁMINAS

¿Cómo funciona?

Cada lámina tiene una clave: su primer número. Las seis claves son 1, 2, 4, 8, 16 y 32.

Un número aparece en una lámina cuando necesita esa clave para formarse. Por eso, al sumar las claves de todas las láminas donde respondiste «Sí», obtenemos tu número.

Por ejemplo, para el número 42:

32 + 8 + 2 = 42

Cada número del 0 al 63 tiene una única combinación de estas claves. Tus seis respuestas nos dicen cuál es la tuya.

Esta es la idea del sistema binario: cada «Sí» es un 1 y cada «No» es un 0. ¡Seis respuestas bastan para descubrir el secreto!
